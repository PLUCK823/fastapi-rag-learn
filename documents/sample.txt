Python 是一种解释型、面向对象的高级编程语言。由 Guido van Rossum 于 1991 年首次发布。
Python 的设计哲学强调代码的可读性，使用缩进来定义代码块。

FastAPI 是一个现代、快速的 Web 框架，用于构建 Python API。它基于 Starlette 和 Pydantic。
FastAPI 的主要特点包括：自动生成 OpenAPI 文档、类型提示驱动、异步支持、数据验证。

LangGraph 是 LangChain 生态中的图编排框架。它用节点和边的有向图来定义 Agent 的工作流。
每个节点是一个处理步骤（比如调用 LLM、检索文档、执行工具），边定义了步骤之间的流转逻辑。
与传统的链式调用不同，LangGraph 支持循环、条件分支、人工审批等复杂控制流。

RAG（Retrieval-Augmented Generation，检索增强生成）是一种结合信息检索和文本生成的技术。
它先从知识库中检索与用户问题相关的文档片段，然后将这些片段作为上下文提供给大语言模型。
RAG 可以有效减少模型幻觉，让回答基于真实数据。

ChromaDB 是一个开源的向量数据库，专为 AI 应用设计。它支持嵌入向量的存储和相似度搜索。
在 RAG 系统中，文档被转换成向量存入 ChromaDB，查询时通过向量相似度找到最相关的内容。
